# Luciano Villavicencio - Portfolio & CV Profesional

Sitio web CV/Portfolio profesional, formal y ultra moderno desarrollado en **React 18**, **TypeScript**, **Vite** y **CSS3** con diseño *Modern-Tech*, modo oscuro/claro y exportación a PDF.

## 🚀 Tecnologías & Herramientas

- **Core**: React 18, TypeScript, Vite
- **Iconos**: Lucide React & FontAwesome 6
- **Estilos**: Custom CSS Design Tokens & Glassmorphism (`src/index.css`)
- **Contacto Directo**: Integración con FormSubmit (AJAX direct email)

## 💻 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar bundle de producción
npm run build
```
